# 🔔 Notification System
Stay informed with real-time session updates through the integrated notification system.

---

## ✨ Available Notifications
| Notification | Description |
|---|---|
| 🏁 **Race Winner** | Displays the winner for each class at the end of a race session. |
| ⚡ **Fastest Lap** | Reports the fastest lap achieved per class. |
| ⚠️ **Penalties** | Notifies drivers about active penalties and sanctions. |
| 🚧 **Track Limits** | Tracks and reports accumulated track limit points. |
| 💥 **Incidents** | Displays collision severity. |

---

## ℹ️ Important Information
The notification system relies on **shared memory data**, which behaves different depending on the session (raked, not ranked and race, practice, etc).

### Supported Session Types
- 🏎️ **Race Sessions**
  - Race Winner
  - Fastest Lap
  - Penalties

- 📊 **Ranked Practice Sessions**
  - Track Limits
  - Incident Reports
